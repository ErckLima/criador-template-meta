# Criador de Template Meta

Ferramenta para montar templates do WhatsApp Oficial (Meta) a partir das mensagens com tags do sistema.

- Converte tags `[TAG]` ou `{{TAG}}` em variáveis `{{1}}`, `{{2}}`...
- Gera a tabela de variáveis com valores de exemplo para o cadastro na Meta.
- Gera o JSON de envio (`template`, `destinatario`, `params`).
- Valida as regras que a Meta costuma recusar.

Acesse pelo GitHub Pages. Tudo roda no navegador; nada é enviado ou salvo em servidor.
